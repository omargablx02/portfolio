Approach

How I Work

Documented, Not Tribal

Anything I build, I write down: the addressing plan, the port map, the switch rule's reason for existing. If I am unreachable, the network still makes sense to whoever picks it up next.

Backups Run Daily, Not Occasionally

Around 44 GB goes out to external storage every working day with Windows Server Backup, across the whole server estate. A backup you skipped is the one you end up needing.

Failures Get Isolated

When hardware fails, I isolate the affected device. With disks that develop bad sectors I move user data to a shared network location so one failing disk does not put it at risk.

Automate the Repetition

If I have typed the same sequence of commands twice, it should be a script the third time. That is the whole reasoning behind my automation work, and it is not glamorous.

Practical Over Trendy

I prefer fixes that are stable and easy to hand over — whether that is a PowerShell script, a TP-Link switch or a UniFi access point.

Close to the Floor

The people on the shop floor are the ones who feel an outage, so I troubleshoot with them rather than only on the server. Understanding the complaint usually finds the fault faster than the logs do.
